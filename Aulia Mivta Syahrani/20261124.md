Lesson Learned

A Data Flow Diagram (DFD) is a visual representation of the flow of data within a system. It illustrates the origin of data, how it is processed, where it is stored, and its destination as it exits the system.

Key Components of a DFD:

• External entities: Parties outside the system that provide input or receive output, such as users, customers, or other systems.

• Processes: Activities or functions that transform input data into output data.

• Data flows: The direction of data movement between components, indicated by arrows.

• Data stores: Locations where data is kept.


DFD Levels:

• Level 0: A high-level overview representing the entire system as a single main process.

• Level 1: A breakdown of the main process from Level 0.

• Level 2 and beyond: Further, more detailed breakdowns of the sub-processes from the previous level.

2. External Entities

- Electrical Grid and PLN Power Supply: Serves as an input source, providing three-phase voltage signals.

- External CT (Current Transformer): Serves as an input source, providing signals.

- Subsystem 2 (Main Processing, Data, and Cryptography): An entity that interacts with process 1.5 via a digital interface.

- Test Bench/Calibration Reference Instrument: An external entity that interacts with process 1.9 for testing and calibration purposes.

Process 1.9 generates calibration pulses (CF1 and CF2), which are sent to the Test Bench/Calibration Reference Instrument.

The Test Bench also provides Comparison Results and Calibration Correction Parameters.


3. Data Stores

- D1 Configuration and Calibration Parameters: Stores configuration data and calibration parameters used in the measurement process (from process 1.2).

- D2 Metrology Register Data: Stores data from process 1.3, specifically the register data resulting from measurements and metrological processing.

- D3 Energy Accumulation: stores data from process 1.6, including the accumulation of active, reactive, and apparent energy.

- D4 Waveform Samples: Stores data from process 1.2, digital voltage and current samples are used for waveform processing and harmonic extraction.
