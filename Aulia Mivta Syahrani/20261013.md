Lesson Learned

Comparison of FRAM with Flash Memory

For example FM25V20A-G-Infineon and WT25Q128

|Parameter|FM25V20A|WT25Q128|
|-|-|-|
|Memory type|FRAM|SPI NOR Flash|
|Capacity|2 Mbit = 256 kB|128 Mbit = 16 MB|
|Interface|SPI|SPI, Dual SPI, Quad SPI, dan QPI|
|Maximum SPI frequency|Up to 40 MHz|Up to 104 MHz|
|Read/write endurance|10^14 read/write cycle|More than 100,000 read/write cycles|
|Data retention|Up to 151 years at 65°C|More than 20 years|
|Operating voltage|2,0 - 3,6 V|2,3–3,6 V|
|Writing mechanism|Able to write without sector erasure wait times.|Writing requires erasing the sector before data is rewritten to the relevant area.|

If storage capacity is the primary priority in smart meter specifications, flash memory is recommended. If the priority is very frequent logging with high write endurance, FRAM is worth considering, though it may require multiple ICs or a combination of memory types.

A bring-up script is a step-by-step guide for powering on and verifying hardware for the first time, detailing register read/write sequences and expected values. Its purpose is to ensure that when the first PCB (spin 1) is ready, the team does not have to start testing from scratch or engage in trial-and-error without a clear procedure.
