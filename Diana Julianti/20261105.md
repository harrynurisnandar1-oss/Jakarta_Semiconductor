Activity Description
Assigned footprints to all components in Subsystem 2 within KiCad (resistors, capacitors, LEDs/diodes, fuses, ferrite beads, headers, test points, switches, and USB connectors), and corrected any footprints that were incorrectly assigned during the automated conversion process. Downloaded the footprint for the XTAL1 (SiT1552) from Ultra Librarian, created the PCB file for Subsystem 2, linked it to the schematic, and executed the "Update PCB from Schematic" function. Verified the 3D models using the 3D Viewer, debugged errors resulting from the update by reviewing the log, mapped the XTAL1 pins according to the datasheet, and adjusted the pad numbering for XTAL1 and J1 in the Footprint Editor. Identified a suitable crystal, Y1 (Abracon ABM3B, 3225 package size).

Lessons Learned
Pad numbers in a footprint must match the pin numbers in the corresponding symbol exactly; discrepancies in formatting—such as "1" versus "01" prevent nets from connecting and trigger errors during the PCB update process. Changes made to a footprint in the library are not automatically reflected on the board; therefore, the "Update Footprints from Library" or "Change Footprints" function must be used. Care must be taken regarding the direction of the update to ensure the schematic is not overwritten. For CSP (Chip Scale Package) components, datasheets often show pinouts from both top and bottom views, which are mirror images of each other; consequently, pin mapping must always be verified against the provided pin map table. Furthermore, reviewing error, warning, and information logs is essential for identifying schematic bugs that may not be apparent on the screen.



Footprints are incorrect or missing following the conversion because KiCad attempted to guess the library; additionally, the "Update PCB" menu option is greyed out because the PCB file was opened separately from the schematic project. Twenty errors occurred during the PCB update, stemming from discrepancies in pad naming for XTAL1 and J1, as well as the pin mapping for XTAL1. The fixes for J1 have not yet been re-verified and will be addressed later tonight.
