Pembelajaran yang Diperoleh

Setup environment dimulai dari install STM32CubeCLT -> memasang 4 ekstensi (C/C++, CMake Tools, Cortex-Debug, Serial Monitor), ekspor proyek dari STM32CubeMX dengan penentuan pin yang digunakan beserta fungsinya.

Ketika membuild suatu program, ada beberapa alat yang bekerja secara berurutan.
- STM32CubeMX: Mengatur fungsi fisik pin dan frekuensi clock dan menghasilkan file aturan build CMakeLists.txt.
- arm-none-eabi-gcc: Menerjemahkan bahasa C menjadi bahasa mesin ARM
- Linker & Linker Script: Menyusun peta memori -> meletakkan kode di flash dan variabel di SRAM

Anatomi CMakeLists.txt mencakupi tetapi tidak terbatas pada hal-hal berikut
- inisialisasi proyek & toolchain
- parameter chip & compiler flags
- daftar path header/file.h
- rujukan berkas linker script
- daftar berkas sumber C & assembly

Dalam pewaktuan, ada dua sifat yaitu blocking dan non-blocking. Blocking akan membuat CPU berhenti selama interval waktu menggunakan fungsi HAL_Delay(). Non-blocking ini tidak menghentikan CPU. CPU masih bisa menjalankan kode lainnya sembari tetap memerhatikan apakah waktu sudah melewati beberapa interval tertentu. Pola non-blocking ini memungkinkan untuk menjalankan dua tugas yang periodik secara bersamaan tanpa harus menghentikan CPU.

Mechanical bounce terjadi pada tombol karena plat logam di dalamnya tidak langsung menempel sempurna. Hal itu menyebabkan pembacaan tombol bisa menjadi tidak stabil (bouncing antara state ditekan/tidak padahal seharusnya stabil di satu state). Bouncing bisa diatasi dengan pendekatan hardware atau software. Penanganan software dilakukan dengan memberi jeda pembacaan agar bouncing tidak terbaca oleh sistem.

Debugging dilakukan untuk memastikan program berjalan sesuai dengan yang diinginkan. Cara memastikannya adalah dengan memasang suatu breakpoint pada baris kode yang ingin diamati, memeriksa nilai variabl dalam RAM, dan memeriksa status register fisik. Langkah-langkah debugging adalah
- siapkan file .svd (file pemetaan seluruh alamat fisik register ke tampilan grafis) dan launch.json (file konfigurasi).
- pasang breakpoint
- mulai debug
- jika kode yang ditandai breakpoint dijalankan, program akan terjeda untuk melihat hasil program
- register bisa dipantau di bagian peripheral
- variabel bisa diamati di bagian watch
