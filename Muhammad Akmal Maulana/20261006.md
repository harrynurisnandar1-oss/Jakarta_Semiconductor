09:50 06/10/2026 Mempelajari TrustZone



ARM TrustZone adalah teknologi keamanan berbasis perangkat keras yang dikembangkan oleh ARM. Konsep utamanya dengan membagi system menjadi 2 dunia terisolasi satu sama lain secara fisik ditingkat prosesor yaitu:



* Normal World (NSC)
* Secure World (SC)



Cara kerja:

* NS-Bit (Non-Secure Bit): Sinyal perangkat keras yang menandai apakah prosesor sedang mengeksekusi instruksi dari Normal World (NS=1) atau Secure World (NS=0)
* SMC (Secure Monitor Call): Pintu gerbang gateway khusus. Saat Normal World ingin meminta layanan aman (misalnua memverifikasi sidik jari), ia mengeksekusi instruksi SMC. Sistem akan beralih ke mode Secure Monitor untuk memverifikasi dan memindahkan control ke Secure World.
* Isolasi Perangkat Keras: Memori (RAM), peripheral, dan cache juga dibagi menjadi area Secure dan Non-Secure menggunakan pengontrol seperti TZASC



13:08 06/10/2026 Mempelajari Secure World pada RISC-V



Konsep Secure World pada RISC-V diimplementasikan secara modulat menggunakan kombinasi Privilege Levels, Physical Memory Protection, dan standar Trusted Execution Environment (TEE)



* Privilege Levels 

|Level Privilege |Nama|Penggunaan / Komponen|
|-|-|-|
|M-Mode (Machine)|Highest Privilege|Firmware, Root-of-Trust, Supervisor Binary Interface)|
|S-Mode(Supervisor)|Intermediate|Kernel OS (Linux,RTOS)|
|U-Mode (User)|Lowest Privilege|Aplikasi pengguna / Unprivileged Tasks|



* Physical Memory Protection (PMP)



Mekanisme Utama untuk membatasi dan mempartisi akses memori berdasarkan privilege level. Cara kerjanya register PMP dikonfigurasi di M-Mode untuk mendefinisikan wilayah memori (address range) dan hak aksesnya (Read, Write, Execute). M-Mode dapat mengunci Sebagian area ram agar S-Mode dan U-Mode sama sekali tidak bisa membaca atau menulis ke area tersebut. Area terisolasi inilah yang membentuk Secure Memory / Secure World.



* Arsitektur TEE



Untuk membuat system dual-world (Rich Execution Environment dan Trusted Execution Environment) ala TZ, RISC-V menggunakan 2 pendekatan Utama:



1. Keystone TEE, Menggunakan M-Mode sebagai Security Monitor dan memanfaatkan PMP untuuk mengisolasi aplikasi sensitif dari aplikasi Utama
2. RISC-V WorldGuard, Menambahkan World ID pada bus transaksi hardware dan memungkinkan pemisahan isolasi tidak hanya pada CPU tapi juga pada peripheral
