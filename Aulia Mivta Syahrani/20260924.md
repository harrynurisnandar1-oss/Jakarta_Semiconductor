Lessons Learned

Understanding the OLED coordinate system is essential for determining character display positions.

The OLED used features a resolution of 128 × 32 pixels, with x-coordinates ranging from 0 to 127 for horizontal positioning and y-coordinates from 0 to 31 for vertical positioning.

The `SSD1306_GotoXY(x, y)` function is used to set the starting position for the character to be displayed.

Microwave measurements indicate that power consumption increases when the appliance is active, evidenced by a rise in current from 0.012 A to 7.278 A.

The PZEM-004T operates by measuring AC electrical parameters of the load—such as voltage, current, power, energy, power factor, and frequency—and storing these measurements in the module's internal registers. The data can then be read via UART communication using the Modbus-RTU protocol. To connect the device to a computer, the PZEM's UART signal is routed through a TTL-to-USB interface.

On the RN8217 MCU, the SWDCLK/P24/RX2 pin serves as the clock for the SWD interface, while the SWDIO/P25/TX2 pin functions as the SWD data line. Both pins are multiplexed, allowing them to serve as UART2 interfaces in addition to their SWD functions.
