Lessons Learned

The RN8217 is a chip that integrates data processing/microcontroller functions with electrical measurement capabilities. It receives voltage and current signals via its analog/ADC section and subsequently performs metering-related processing and calculations.

The PLN LoRa modem is a dedicated smart telemetry embedded system designed to read electricity usage data from the main meter via an RS-232 serial interface (processed by the MA3232C IC), store it in SPI Flash memory (Winbond 25Q32), and wirelessly transmit it to the PLN server via a LoRa transceiver.

The OLED utilizes two I2C communication lines: SCL, which serves as the clock, and SDA, which acts as the data line.

SCL functions as the clock signal, determining when each bit on the SDA line is read. SDA carries addresses, commands, and data from the STM32 to the OLED.
The SSD1306 is the driver/controller integrated into the OLED module; it manages the OLED pixels based on commands and data received from the STM32 via I2C communication.
The STM32 Nucleo-G474RE first sends a START signal and the OLED address (`0x3C`), then receives an ACK (acknowledgment) indicating that the OLED has accepted the communication. Once the SSD1306 is initialized, bitmap data for the text "Hello World" is transmitted via SDA, with timing regulated by SCL. The SSD1306 then receives and processes this data into a pixel pattern on the OLED screen, allowing "Hello World" to be displayed.
