## Istilah-istilah yang akan dipelajari.

Encrypt: Scrambling data to make it unrecognizable.

Decrypt: Unscrambling data to its original format.

Cipher: Another word for algorithm.

Key: A complex sequence of alpha-numeric characters, produced by the algorithm, that allows you to scramble and unscramble data.

Plaintext: Decrypted or unencrypted data (it doesn’t have to be text only).

Ciphertext: Data that has been encrypted.

## Ciphers
A cipher is an early or fundamental form of an encryption algorithm.
Purpose & Function: Ciphers are used to conceal, scramble, and transform data so that secret messages cannot be read by unauthorized parties.
### Types of ciphers.

1. Concealment ciphers have been used for centuries to hide a message in plain sight.
2. Substitution ciphers requests the replacement of a single letter or character with another based on a specific pattern. The original character is changed into a new one.
3. Transposition Cipher alters the order or position of characters within a message without replacing the letters with other characters. The letters of the original message remain the same, but their arrangement is scrambled (like an anagram), rendering the text unreadable until it is rearranged into its original order.

### Hash
- A hash is a one-way function. It converts data into a hash value, but the original data is not designed to be recovered or decrypted from the hash.
- A hash algorithm processes the input through a series of mathematical operations and produces a fixed-length output, usually represented as alphanumeric characters.
- The primary purpose of hashing is to verify data integrity. It can determine whether data has been modified during transmission or storage.
- When receiving data together with its hash value, the receiver runs the same hash algorithm on the received data:
- If the resulting hash matches the original hash → the data is likely unchanged.
- If the hash does not match → the data has been modified or corrupted.
- Hashes are also commonly used to verify software integrity. Software vendors may publish a hash value for a program so users can compare it with the hash of the downloaded file.
- If the hashes are different, the file may be corrupted, modified, or compromised, potentially containing malicious software such as a Trojan.

### XOR (exclusive OR)
Berdasarkan teks yang Anda berikan, berikut adalah poin-poin utama mengenai operasi XOR:

* **Bukan Algoritma Kriptografi Mandiri:** XOR adalah operasi matematika (*Exclusive-Or*), bukan skema enkripsi utuh. Penggunaan XOR tunggal sangat mudah dipecahkan dan tidak memberikan perlindungan keamanan yang memadai.
* **Peran dalam Kriptografi Modern:** XOR digunakan secara intensif dan berulang (*multiple iterations*) di dalam berbagai algoritma enkripsi modern untuk mengacak data secara efektif.
* **Aturan Operasi Biner:**
* Nilai bit **sama** ($0 \oplus 0$ atau $1 \oplus 1$) $\rightarrow$ hasil **$0$**
* Nilai bit **berbeda** ($1 \oplus 0$ atau $0 \oplus 1$) $\rightarrow$ hasil **$1$**

* **Sifat Reversibel (*Symmetric Property*):** Dekripsi dilakukan dengan menerapkan operasi XOR ulang menggunakan kunci yang sama pada *ciphertext*:

$$\text{Plaintext} \oplus \text{Key} = \text{Ciphertext}$$

$$\text{Ciphertext} \oplus \text{Key} = \text{Plaintext}$$
