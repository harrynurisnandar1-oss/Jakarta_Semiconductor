09:39 22/09/2026 Watchdog

Watchdog is a special hardware circuit or software toll that automatically resets a microcontroller or system if the software srashes or gets stuck in an endless loop

A WDT expires when the countdown counter reaches zero because the software failed to reset "feed" it in time



How a watchdog works

* The counter: a watchdog uses a countdown timer that continuously count down to zero
* The Feed (Kick/Pet): During normal operation, software must regularly reset or feed the timer befor it reaches zero
* The Reset: If a bug, lockup, or power glitch stops the code from feeding the timer, the counter hits zero and forces a hardware reset to restart the system safety
