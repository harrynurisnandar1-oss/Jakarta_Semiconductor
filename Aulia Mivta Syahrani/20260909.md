Lessons Learned

It was observed that when using two channels on the logic analyzer, the microcontroller's button signal failed to appear in Saleae Logic because one of the pins did not receive sufficient power.

The TIM2 configuration was understood for generating a 1 ms periodic interrupt and utilizing a tick counter to produce a 1 Hz LED blink on the Nucleo G474RE, followed by signal accuracy verification using a logic analyzer.

The implementation of PWM on the timer was understood, specifically by modifying the duty cycle through programming to adjust the LED brightness level incrementally.

It was recognized that a tick counter is a timer-interrupt-based counter used to measure time intervals and execute processes periodically without relying on direct delay functions.

The results showed that the LED did not light up when the variable was not declared as `volatile`, whereas it did light up after the variable was declared using the `volatile` keyword.


Obstacles Encountered
