2:10 PM 9/21/2026 Berhasil mencoba menjalankan FreeRTOS pertama pada board STM32U575VGT6, LED PB7 berkedip tiap 500 ms dari sebuah task, lewat ST-LINK.

FreeRTOS pakai SysTick untuk tick-nya, jadi timebase HAL harus dipindah ke timer lain (TIM6) supaya tidak bentrok.
osDelay() membuat task tidur dan CPU bisa dipakai task lain, sedangkan HAL_Delay() menahan CPU. 

Yang ditambahkan di kode : 
BlinkTask: isi tugasnya, berupa loop for(;;) yang membalik LED lalu osDelay(500). Task tidak boleh selesai, jadi harus berupa loop tanpa akhir.

/* USER CODE BEGIN Application */
void BlinkTask(void *argument)
{
  for(;;)
  {
    HAL_GPIO_TogglePin(LED1_GPIO_Port, LED1_Pin);
    osDelay(500);
  }
}
/* USER CODE END Application */


osThreadNew(BlinkTask, NULL, &blink_attr) di RTOS_THREADS: mendaftarkan task ke FreeRTOS beserta nama, ukuran stack (1 KB), dan prioritas. Task baru berjalan setelah osKernelStart().

/* USER CODE BEGIN RTOS_THREADS */
  /* add threads, ... */
  const osThreadAttr_t blink_attr = {
    .name = "blink",
    .stack_size = 256 * 4,
    .priority = (osPriority_t) osPriorityNormal,
  };
  osThreadNew(BlinkTask, NULL, &blink_attr);
  /* USER CODE END RTOS_THREADS */


Prototype void BlinkTask(void *argument); di FunctionPrototypes: supaya compiler mengenal nama fungsi sebelum isinya ditulis.

3:52 PM 9/21/2026 Berhasil menjalankan 2 task FreeRTOS bersamaan: LED PB7 berkedip tiap 500 ms dan LED PC7 tiap 200 ms. 

Pola menambah task selalu sama: prototype, osThreadNew di RTOS_THREADS, isi fungsi. Tinggal ganti nama, pin, dan waktu tidur.
CPU-nya cuma satu, jadi task tidak benar-benar jalan bersamaan. Scheduler yang bergantian memberi giliran. Kelihatan bersamaan karena tiap task hampir selalu tidur (osDelay) dan hanya bangun sebentar untuk membalik LED.
Saat semua task tidur, CPU menjalankan idle task. Di sinilah nanti MCU bisa dibuat tidur hemat daya (dasar low power).
defaultTask masih bangun tiap 1 ms lewat osDelay(1). Nanti waktu masuk low power, ini perlu dibereskan supaya MCU bisa tidur lebih lama.
