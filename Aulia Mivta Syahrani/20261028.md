Lesson Learned

RegisterMap.h contains a list of register addresses and parameter names for the ADE9000.

Mock.c and Mock.h emulate the ADE9000 by providing simulated register values, allowing the program to run without the physical chip.

Metrology.c and Metrology.h read these simulated values, convert them into electrical units, and then calculate the required parameters.

SPI.c and SPI.h handle register access via SPI communication functions.

Main.c calls the metrology functions and displays the measurement results.


Obstacle Encountered

The development of the metrological LED pulse program could not be completed as planned; upon reviewing the SPLN standard, it was discovered that several metrological parameters had not yet been incorporated into the simulation program. Consequently, the focus of the work has been shifted to first ensuring these parameters are included.
