Lesson Learned

A power limiter setting defines the maximum power limit permitted for a customer's consumption. If this established limit is exceeded, the feature can trigger a relay or contactor to disconnect the power supply.

A power limiting setting is a configuration parameter used as a threshold or reference for power control functions; it is not a measurement output.

Power limiting settings are determined by PLN and configured within the smart meter.

The meter includes a power-limiting feature that can be set to a specific value, which causes the relay/contactor to open.
