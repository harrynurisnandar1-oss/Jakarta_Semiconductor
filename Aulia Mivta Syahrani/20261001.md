Lesson Learned

Understanding that a 3 phase smart meter measures RMS voltage and current and calculates active power, then accumulates active power over time to obtain active energy in kWh.

AWATT_ACC represents the accumulated total active power, while AWATTHR represents the accumulated total active energy.

The SPI abstraction layer serves to provide simple interface functions such as read and write register, so that other parts of the firmware do not need to interact directly with the intricacies of SPI communication. Meanwhile, the SPI transaction layer manages the SPI transaction process in greater detail, handling tasks such as command header formation, data transmission and reception sequencing, burst read operations, and CRC (Cyclic Redundancy Check) in accordance with the ADE9000 communication protocol.
