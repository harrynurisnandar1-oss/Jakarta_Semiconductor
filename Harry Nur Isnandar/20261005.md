* **Implementasi API Kriptografi (Facade):** Telah dibuat sebuah antarmuka keamanan (`ami_security.h`) yang menangani *random number generation* dan enkripsi/dekripsi terautentikasi (AEAD). API ini bertindak sebagai batas keamanan (*cryptographic boundary*) yang mencegah kode aplikasi mengakses material kunci (*raw key bytes*) secara langsung.
* **Simulator Host Berbasis OpenSSL:** Pengembangan *backend* bernama `ami_security_host` yang menggunakan OpenSSL untuk mensimulasikan lingkungan kriptografi pada PC. Simulator ini mengelola kunci secara in-memory khusus untuk memfasilitasi proses *development* dan pengujian.
* **Penyertaan Modul STS Prabayar:** Repositori saat ini sudah berisi contoh implementasi sistem prabayar STS (Standard Transfer Specification) yang berjalan di sisi *host*.
* **Kerangka Pengujian Terotomatisasi (CTest):** Skrip CMake telah dikonfigurasi untuk menjalankan pengujian. Ini mencakup tes mandiri untuk API keamanan AMI portabel yang dapat dijalankan tanpa dependensi, serta pengujian yang lebih luas (kriptografi STS, metrologi, dan energi) jika *host tools* OpenSSL diaktifkan.
