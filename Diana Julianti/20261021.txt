DSU (DynamlQ Shared Unit) 
•	DSU (v8) is the 1st generation of DynamlQ shared unit.
•	DSU specification versions supported.
•	DSU Configuration of Cores (Maximal 8 cores in total).
DSU Memory Interfaces 
•	Manager interface :ACE5 or CHI protocol
•	Subordinate interface : ACP 
DSU – ACE Manager Interface 
•	DSU can be implemented with one or two CHI interfaces (AMBA 5 CHI protocol).
•	Two interfaces give greater bandwidth for memory transactions.
DSU-ACP Subordinate Interface 
•	ACP interface conforms subset of ACE5-Lite specifitaction
DSU-AXI Manager Peripheral Port
•	Provides low-latency access to tightly coupled devices.
DSU L3 Cache
L3 Cache Overview 
•	L3 cache sizes: 256KB 512KB 1MB 1.5 MB 2MB 3MB or 4 MB
L3 Cache Features
•	Dynamically optimized cache allocation policy: exclusive allocation (data is allocated only in 1 core), Inclusive allocation (data is shared between cores)
•	Cache stashing : On CHI interface , On ACP interface.
L3 Cache Features - Partitioning 
•	L3 Cache supports partitioning scheme: Achieved by groups of cache ways and partition scheme IDs alters victim selection policy.
•	Private to one Scheme ID, or To more than one Scheme IDs, or To be left unassigned, can be shared by all 8 Scheme IDs
•	Each core must be assigned to at laeast 1 Scheme ID
L3 Cache Features – Cache Slices & ECC
•	L3 cache ECC:
SECDEC ECC on the L3 data RAMs (per 64 bit)
DSU Clocks and Power Management

•	Fetches instruction from L1 instruction cache
•	IFU includes:
A 64KB, 4-way, set associative L1
A fully associative L1 instruction TLB with native support 
A dynamic branch predictor
Cortex-A76 - Decode, Rename Issue:
•	Instruction decode unit (supports the A32, T32, and A64 instruction sets)
•	Register rename unit (performance register renaming to facilitate out0of-ordr execution)
•	Instruction issue unit (Include issue queues for storing instruction)
Execution pipeline, L1 and L2 memory system 
•	Execution pipeline : integer execute unit that performs arithmetic and logical data processing operations.
•	L1 data memory system
•	L2 data memory system (An 8-way set associative L2 cache with data ECC)
