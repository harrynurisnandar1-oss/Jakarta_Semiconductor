Lesson Learned

CF_LCFG is not an energy accuracy calibration register. It configures the CFx pulse shape/output, which is proportional to accumulated energy. While the ADE9000 does feature CF1–CF4 outputs that can serve as energy or calibration pulses, metering accuracy is calibrated using registers such as gain, phase, and so forth.

Determining the CF_LCFG value involves several steps: selecting the CF output channel and the CFx_LT bit; setting the active-low pulse width; calculating the CF_LTMR value based on CLKIN; and finally, combining these parameters into the CF_LCFG value and applying it to the register via code.

Dip and swell detection in the ADE9000 is performed based on the voltage RMS½ value, the DIP_LVL/SWELL_LVL thresholds, and the DIP_CYC/SWELL_CYC detection durations; measurement results and event statuses are stored in registers, and the system is notified via an interrupt.

The ADE9000 calibration program utilizes RegisterMap.h to store ADE9000 register addresses; Mock.c/Mock.h to simulate ADE9000 functions and responses without physical hardware; SPI.c/SPI.h to handle SPI-based communication and data transactions; Metrology.c/Metrology.h to process register data into metrological quantities; and Calibration.c/Calibration.h to execute the calculation and application of calibration parameters.
