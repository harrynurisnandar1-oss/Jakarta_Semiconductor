Lesson Learned

Basic current (Ib) is a standardized reference value used to determine the required accuracy level of a meter when tested under various current conditions.

In the IEEE context, maximum current (IL) refers to the maximum load current used as a reference for calculating Total Demand Distortion (TDD). Meanwhile, in the SPLN context, Im represents the meter's maximum current, the highest current permitted to flow continuously while ensuring that accuracy requirements are still met.
