08:00 01/10/2026 Mempelajari lebih dalam fungsi ECDH STS 

![alt text](ECDH.png)

menggunakan persamaan kurva eliptik dan perkalian skalar titik untuk menghasilkan kunci rahasia bersama
persamaan kurva eliptik dasar

**y<sup>2</sup> = (mod *p*)**

atau secara umum 

**y<sup>2</sup> = x<sup>3</sup> + ax + b (mod p)**

dengan syarat 4a<sup>3</sup> + 27b<sup>2</sup> ≠ 0

Parameter Publik yang Disepakati :
- **E**: Kurva eliptik yang digunakan.
- **P** (atau **G**): Titik dasar (base point / generator) pada kurva.

Langkah-Langkah dan Rumus Pertukaran Kunci
1. Pembuatan Kunci oleh Alice
- Kunci Privat (***d<sub>A</sub>***): Alice memilih angka acak rahasia (***d<sub>A</sub>***).
- Kunci Publik (***Q<sub>A</sub>***): Alice menghitung titik publiknya dengan perkalian skalar:
***Q<sub>A</sub>*** = ***d<sub>A</sub>*** X **P**
- Alice mengirim ***Q<sub>A</sub>*** ke Bob.

2. Pembuatan Kunci oleh Bob
- Kunci Privat (***d<sub>B</sub>***): Bob memilih angka acak rahasia (***d<sub>A</sub>***).
- Kunci Publik (***d<sub>A</sub>***): Bob menghitung titik publiknya:
***Q<sub>B</sub>*** = ***d<sub>B</sub>*** X **P**
- Bon mengirim ***Q<sub>B</sub>*** ke Alice.

3. Perhitungan Kunci Bersama (Shared Secret)
- Alice menerima ***Q<sub>B</sub>*** dari Bob, lalu menghitung:
***Secret<sub>A</sub>*** = ***d<sub>A</sub>*** X ***Q<sub>B</sub>*** = ***d<sub>A</sub>*** ( ***d<sub>A</sub>*** X **P**)
- Bob menerima ***Q<sub>A</sub>*** dari Alice, lalu menghitung : 
***Secret<sub>B</sub>*** = ***d<sub>B</sub>*** X ***Q<sub>A</sub>*** = ***d<sub>B</sub>*** ( ***d<sub>A</sub>*** X **P**)

Secara matemati Hasil keduanya :

Shared Secret = ***d<sub>A</sub>*** X ***d<sub>B</sub>*** X P
