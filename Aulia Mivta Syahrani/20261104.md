**Signal processing flow in Figure 62 – Total Active Power (AWATT)**

<img width="224" height="94" alt="image" src="https://github.com/user-attachments/assets/a57cceb8-63fc-4597-a55d-2a79314b47f0" />


1. Signal input -> AI_PCF and AV_PCF serve as inputs, consisting of sampled current and voltage signals for phase A.

2. Signal multiplication -> The multiplication symbol (×) multiplies the current samples by the voltage samples to obtain the instantaneous active power value.

3. Filtering -> LPF2 processes the result of the multiplication to extract the average active power component. LPF2 is enabled during normal operation by setting DISAPLPF = 0.

This operation is consistent with the standards specified in SPLN.

<img width="194" height="88" alt="Daya Aktif SPLN" src="https://github.com/user-attachments/assets/f32cc28e-f0db-4c32-aad6-eb2e157b3217" />

4. Gain correction -> The APGAIN block applies a gain correction to the active power measurement result.

5. Offset correction -> The summation symbol (Σ) adds an offset correction value derived from the AWATTOS register.

6. Output -> The processed result is stored in the AWATT register as the active power value for phase A.


**Signal processing flow in Figure 63 – Total Reactive Power (AVAR)**

<img width="223" height="89" alt="image" src="https://github.com/user-attachments/assets/99c3bc16-0385-42fc-bd7d-f680ef673b73" />

1. Signal input -> AI_PCF and AV_PCF serve as inputs, consisting of sampled current and voltage signals for phase A.

2. Phase shift -> The 90-Degree Phase Shift block shifts the phase of the current signal by 90°.

The reactive power component can be obtained by multiplying the voltage by the current signal that has been shifted by 90°.

Without the phase shift, the multiplication of voltage and current yields a component related to cos 30°, which represents active power.
Once the current is shifted by 90°, the multiplication yields a component related to cos(90° - 30°) = sin 30°, which represents reactive power.

3. Signal multiplication -> The multiplication symbol (×) multiplies the current signal—which has undergone a 90° phase shift—by the voltage signal.

VAR = VRMS × (IRMS × sin(phi))

4. Filtering -> LPF2 processes the result of the multiplication to obtain the average reactive power component. LPF2 is enabled during normal operation by setting DISRPLPF = 0.

5. Gain correction -> The APGAIN block applies a gain correction to the reactive power measurement result.

6. Offset correction -> The summation symbol (Σ) adds an offset correction value from the AVAROS register.

7. Output -> The processed result is stored in the AVAR register as the reactive power value for phase A.


**Signal processing flow in Figure 64 – Total Apparent Power (AVA)**

<img width="223" height="134" alt="image" src="https://github.com/user-attachments/assets/1c6e6a3c-4955-4a5b-8896-19e0e9dd4917" />

Figure 64 features two processing paths: a current path and a voltage path. Both paths generate RMS values, which are then multiplied to obtain the apparent power.

A. Current processing path

1. Signal input -> AI_PCF serves as the input, consisting of sampled current signals for phase A.

2. Squaring -> The x² symbol squares each current signal sample.

3. Filtering -> LPF2 processes the squared values ​​to obtain the average of the squared components.

4. Offset correction -> The summation symbol (Σ) adds an offset correction derived from AIRMSOS, multiplied by a factor of 2¹⁵.

5. Square root -> The square root symbol produces the RMS value of the phase A current.

6. Current path output -> The result is AIRMS, representing the RMS value of the phase A current.

B. Voltage processing path

1. Signal input

AV_PCF serves as the input, consisting of sampled voltage signals for phase A.

2. Squaring -> The x² symbol squares each voltage signal sample. 3. Filtering -> LPF2 processes the squared result to obtain the mean-square component.

4. Offset correction -> The summation symbol (Σ) adds an offset correction—derived from AVRMSOS—multiplied by a factor of 2^(15).

5. Square root -> The square root symbol produces the RMS value for the phase A voltage.

6. Voltage value selection -> The VNOM and VNOMx_EN blocks allow for the use of a nominal voltage value instead of the measured AVRMS result. Whether this option is used depends on the configuration of the VNOMx_EN bit in the CONFIG0 register.

7. Voltage path output -> The result is either the AVRMS value or the selected nominal voltage value.


C. Apparent power calculation

1. RMS value multiplication -> The multiplication operator (×) multiplies the RMS current value by the RMS voltage value.

This operation aligns with the standards referenced in the SPLN.

<img width="89" height="55" alt="Daya Semu SPLN" src="https://github.com/user-attachments/assets/e1737e64-4c3a-4bd1-9215-c5aaf9cb7f4f" />

2. Gain correction -> The APGAIN block applies a gain correction to the result of the multiplication.

3. Output -> The processed result is stored in the AVA register as the apparent power value for phase A.
Note: A similar path is used for phases B and C, with the results stored in the BVA and CVA registers, respectively. All three are updated at a rate of 8 kSPS.


**The procedure for determining the power factor, based on the datasheet**, is as follows:

<img width="181" height="143" alt="image" src="https://github.com/user-attachments/assets/9774bcee-9ec9-4c9a-bec6-9692eaedec83" />

1. Power factor calculation -> The ADE9000 performs an internal power factor calculation for each phase.

2. Determining the power factor sign -> The sign of the power factor for phase A follows the sign of the active power in the AWATT register. The same logic applies to phases B and C.

3. Determining load characteristics -> The quadrant diagram in Figure 71 illustrates the relationship between the signs of active power (WATT) and reactive power (VAR), which is used to identify whether the load is inductive or capacitive, as well as whether it is in a leading or lagging condition.

4. Storing results -> The calculated power factor for each phase is stored in the APF and BPF registers.

5. Register value conversion -> The power factor value is stored in a signed 5.27 format. To obtain the power factor value in decimal form, the following equation is used:

Power Factor = xPF × 2^(-27)
