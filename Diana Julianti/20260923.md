Modul komunikasi AC PZEM-004T : yang dipakai untuk mengukur parameter listrik arus bolak-balik (AC) satu fasa secara digital dan akurat.

Terdapat dua tipe modul:
- PZEM-004T-10A : rentang pengukuran arus hingga 10 A, menggunakan shunt internal ("ini yang dibawa bapak").
- PZEM-004T-100A : rentang pengukuran arus hingga 100 A, menggunakan transformator eksternal/CT.

Kode sumber inti FreeRTOS terkandung dalam dua file C yang umum digunakan oleh semua port FreeRTOS. File-file tersebut adalah `tasks.c` dan `list.c. Selain itu ada queue.c, timers.c, event_groups.c, croutinr.c.

- "list.c"
- "tasks.c"
- "queue.c" menyediakan layanan antrean "queue" dan "semaphore". "queue.c" hampir selalu diperlukan.
- "timers.c" menyediakan fungsionalitas "software timer". File ini hanya perlu disertakan dalam proses "build" jika "software timer" benar-benar akan digunakan.
- "event_groups.c" menyediakan fungsionalitas "event group". File ini hanya perlu disertakan dalam proses "build" jika "event group" benar-benar akan digunakan.
- "croutine.c" mengimplementasikan fungsionalitas "co-routine" FreeRTOS.

*Co-routine* tidak dijelaskan dalam buku, mengapa? karena Co-routine dibuat khusus untuk RAM kecil sedangkan arsitektur mikrokontroler modern sudah memiliki RAM yang jauh lebh besar.

File sumber yang spesifik untuk port FreeRTOS tertentu terdapat di dalam direktori `FreeRTOS/Source/portable`.
